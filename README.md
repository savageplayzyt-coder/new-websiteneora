# Nexora Labs

A responsive, single-page company website built with plain HTML, CSS, and JavaScript. No package manager or build step is required.

## Run locally

Open `index.html` in a modern browser. For local development, serve this folder with any static HTTP server.

## Included interactions

- Responsive navigation with a keyboard accessible mobile menu
- Light and dark themes, with the selected theme saved in the browser
- Project filtering by category
- Rotating client testimonials
- Contact form validation and accessible inline feedback
- Scroll reveal effects that respect reduced-motion preferences

## Contact form

The form validates the fields and shows a demo confirmation. It does not transmit or store submissions. Connect it to a form service or your own API before using it to receive inquiries. The example email address uses the reserved `.example` domain.

## Files

- `index.html` — page content and structure
- `styles.css` — layout, themes, responsive styling, and animation
- `script.js` — navigation, filters, theme, testimonial, and form behavior
